## Observed sequence and results

1. The existing task was saved as the comparison baseline while v0.1.0 was running.
2. Ansible applied the verified v0.1.1 release inputs. The health response identified
   v0.1.1 and the original saved task was unchanged.
3. Ansible applied the verified v0.1.0 release inputs using the corrected playbook.
   The original saved task remained unchanged after the rollback.
